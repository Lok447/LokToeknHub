# LokToken 浏览器 UAT 记录

验证日期：2026-08-19

## 已通过

- 管理控制台：超级管理员登录、运营人员登录、审计员登录；审计员可查看但看不到模型写操作入口，运营人员可管理模型但不显示超级管理员专属预检入口。
- 用户中心：新用户注册、登录、用户概览、模型广场、额度管理、API 管理、请求记录、订单管理、兑换福利和账号安全页面均可进入。
- 密钥治理：创建 Key 后只展示一次；轮换后旧 Key 停用、新 Key 可用。
- 密码安全：登录页已补充“忘记密码？”入口；预发布环境可申请一次性凭证并完成密码更新，旧密码返回 401，新密码可登录。
- 福利和额度：测试兑换码兑换成功，额度即时到账；真实 DeepSeek 请求后余额、Token、费用和账本流水一致。
- 模型调用：`deepseek-v4-flash` 非流式真实请求成功，供应商返回 88/8/96 usage；用户请求记录显示 96 Token、费用 ¥0.000336。
- 订单运营：用户创建人工充值申请，超级管理员确认后进入 `paid`，随后退款进入 `refunded`；账本对账返回一致。
- LokSystem 登录：本机 SSO 入口可用；未登录 LokSystem 桌面端时按预期返回“请先登录 LokSystem desktop”提示，不伪造成功登录。
- 自动化回归：`scripts/gate_live.py` 在独立 PostgreSQL Gate 中通过；测试套件 `33 passed`。
- 运行时复核：发现 8000 端口原先由系统旧版 FastAPI 进程提供，管理员登录会返回 500；已切换为项目 `uv` 锁定环境并重启，`/healthz`、`/readyz` 和管理员登录均返回 200。
- 响应式检查：用户中心 7 个页面、管理控制台 8 个页面分别在 `1440x1000` 和 `390x844` 视口完成 DOM/交互检查，均无横向溢出；移动端导航和纵向滚动可用。
- 权限呈现：超级管理员显示模型预检/批量接入/添加模型等入口；运营人员保留运营写入口但隐藏超级管理员预检；审计员模型行显示“只读”且不显示写入口。
- 模型广场：管理端模型类型筛选显示文本、图像、视频、语音四类计数，模型管理页可正常加载 29 条模型配置。
- 测试数据收口：本轮 `uat-*` 管理员、浏览器 UAT 用户及其活动 Key 已停用并保留审计记录；停用后管理员登录返回 401，用户登录返回 403。

## 环境限制

桌面与移动截图生成未完成：本机 C 盘曾耗尽空间，清理本轮明确创建的旧运行时缓存后仅恢复约 180 MB，仍不足以稳定创建独立无头浏览器配置。现有浏览器 DOM/交互检查已完成，但发布前仍应在有至少 2 GB 可用空间的预发布机器上补跑 `1440x1000` 和 `390x844` 截图，并检查横向溢出、表格滚动和弹窗可见性。
