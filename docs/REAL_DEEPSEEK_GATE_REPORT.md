## 成本结论与上线阻断

当前平台固定价在 Off-peak 低于官方实际销售成本风险较低，但在 Peak cache-miss 场景下，输出价 `9.000` 元 / 1M 低于官方 `9.504` 元 / 1M，可能出现毛利倒挂。平台还没有把供应商的 cache hit/miss、peak/off-peak 维度写入 usage 账本。

真实生产放行前必须完成：

1. 获取 DeepSeek 账户可导出的 API 消费明细（包含时间、模型、Token、金额或可关联请求标识），按 `provider_request_id`、usage、时间段逐笔核对；当前网页已验证到模型/请求数/Token 聚合层级。
2. 决定平台价格采用 peak-safe 价格、动态时段价格，或把官方成本加上运营加价后统一换算。
3. 扩展 usage 账本保存 `cache_hit_tokens`、`cache_miss_tokens`、供应商成本、平台收入和毛利字段。
4. 流式失败目前只能在 HTTP 连接已经建立后以 SSE error event 返回，客户端看到的是 HTTP 200；SDK/文档必须明确以 error event 和 usage 记录判断最终结果，不能只看 HTTP 状态。
5. 配置第二真实备用渠道后，再验证真实渠道失败重试、熔断打开、备用渠道接管和恢复。
