01 / 开始使用

注册或使用试用链接进入

在用户中心可直接注册账号，也可以使用管理员发放的试用链接进入。注册账号用于长期使用；试用链接创建的 API Key 会跟随试用期限自动失效。

登录后可在右上角确认当前账户身份；退出会清除当前浏览器会话。

02 / 选择模型

在模型广场确认可调用能力

模型广场提供公开模型名称、能力标签、价格、渠道健康状态和 OpenAI 兼容调用示例。将示例中的 YOUR_API_KEY 替换为自己的 Key 后即可接入。

  • 优先选择显示“渠道健康”的模型。
  • 调用请求中的 model 必须使用模型广场显示的公开模型 ID。
  • 模型价格以输入和输出 Token 分别结算。

03 / 获取额度

通过福利兑换或充值申请补充额度

新注册账户默认余额为 0。可在“兑换福利”输入有效兑换码，额度会即时到账；也可以在“额度管理”创建充值申请，待运营人员确认后入账。

当前阶段不接入真实在线支付。订单状态、到账时间和退款状态可在订单管理中追踪。

04 / 创建 API Key

为应用创建独立凭证

在密钥管理中创建 Key，可按应用设置名称、有效期和消费上限。完整 Key 只在创建成功时显示一次，后续只能查看前缀。

curl https://YOUR_DOMAIN/v1/chat/completions \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"deepseek-v4-flash","messages":[{"role":"user","content":"你好"}]}'

如果账户余额不足，接口会返回 402，并在 error.code 中返回 insufficient_balance；请先充值或兑换额度。401 才表示 API Key 无效或已过期。

05 / 查看记录

用请求记录排查调用问题

请求记录支持按时间、模型、API Key、状态和请求 ID 筛选。详情中可查看 Trace ID、Token、耗时、费用和错误信息；不会展示或保存模型输入、输出正文。

需要对接程序时，可使用右上方 OpenAPI 参考查看完整参数和响应结构。

01 / 模型管理

接入上游并维护统一模型目录

系统初始化时会预置 DeepSeek、Qwen、GLM、Kimi、MiniMax 和 Doubao 的常用文本、多模态、图像与视频候选，后续也可新增单个模型或批量读取 OpenAI 兼容上游目录。候选默认停用，不会在价格、密钥和真实渠道检测完成前向用户发布。

  • 每个公开模型可配置多个渠道，按优先级和权重路由。
  • 供应商密钥可由控制台加密保存，也可引用部署环境变量；页面只显示配置状态，不回显明文。
  • 通过“检测全部渠道”确认上游 /models 的可用性，再设置平台价格、执行预检并启用。
  • 图像和视频模型当前作为候选目录展示，需等待对应统一调用适配器与计费规则启用。

02 / 账户与密钥

管理账户、余额和访问凭证

账户管理用于维护 LokSystem 用户与共享余额；密钥管理用于创建、停用和审查 API Key。管理员还可为账户生成限时试用链接。

API Key 是实际调用模型网关的凭证；用户中心会话令牌不能用于调用 /v1 接口。

03 / 订单与福利

处理额度发放，不直接处理真实支付

订单管理记录用户充值申请，可在确认到账后入账或执行退款。福利管理可创建限次、可过期的兑换码，用于试用、活动和线下发放。

所有额度变动都写入账户流水，重复确认和重复兑换均受幂等约束。

04 / 运营与审计

从用量管理和安全审计观察平台

用量管理展示近期模型调用的账户、API Key、模型、Token、费用和状态。安全审计记录关键运营动作和用户门户动作，不记录密钥、请求正文或模型输出。

05 / 上线检查

生产发布前完成最小安全配置

  • 关闭 Mock 模式和自动建表，使用 Alembic 管理数据库迁移。
  • 替换管理员、支付回调和会话签名密钥，均应使用独立高强度随机值。
  • 配置 HTTPS 域名、可信 CORS 来源、数据库备份和网关层共享限流。
  • 在模型管理完成真实供应商渠道配置和健康检查后，再向用户公开模型。
